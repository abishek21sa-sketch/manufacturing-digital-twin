# Future Work — Post V1.0

V1.0 is feature-frozen. The following are deliberately outside the release rather than hidden completion requirements:

- named-plant MES/ERP/SCADA/IIoT connectors and schema contracts;
- plant-calibrated processing/failure/repair distributions and drift monitoring;
- larger dynamic rolling-horizon instances and decomposition/scale studies;
- alternate-routing/network decisions if a future manufacturing environment actually contains route choices;
- CP-based scheduling only if benchmarking shows material scale/performance value versus the verified MILP;
- richer operator authentication/authorization and site security integration;
- production telemetry/observability integration;
- controlled field trial, site acceptance and measured realized operational impact.
